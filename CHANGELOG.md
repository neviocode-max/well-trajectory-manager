# Changelog

## 1.0.0

Initial production release of the React/TypeScript WTM application.

### Included

- Empty-database startup
- Database import, append, QC, editing and export
- Trajectory Converter and Splitter
- Coordinate Converter
- Well Distance analysis suite
- Trajectory Studio
- Responsive desktop/tablet/mobile UI
- Windows Azure App Service packaging
- Future Microsoft Entra ID integration boundary
- Regression/parity test suite based on fictional data

### Professional cleanup

- Consolidated product-facing terminology and removed migration-status wording from the UI
- Refined navigation, toolbar, status and database-state presentation
- Added dependency-free SVG navigation/status icons
- Standardized controls, cards, tables, messages, modals and focus states
- Simplified repository documentation for production use
