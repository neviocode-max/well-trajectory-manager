# Phase 1 numerical parity benchmarks

The expected values below were generated by executing the original WTM 4.3 engineering functions against fictional synthetic wells (`DEMO-01`, `DEMO-02`, `DEMO-03`). They are used as golden regression values for the TypeScript engine.

Validated benchmark groups:

1. Minimum-curvature delta
2. Exact partial minimum-curvature interpolation
3. Interpolated station position/orientation
4. Dogleg severity (deg/30 m)
5. Multiple TVD solution detection
6. Point-to-well 3D closest distance
7. Well-to-well 3D closest approach
8. Same-elevation 2D well distance
9. WGS84 Lat/Lon ↔ UTM conversion

Selected reference values:

```text
MCM dTVD      94.62867168383083
MCM dN        67.48694709805608
MCM dE        17.934193866165245
DLS           6.462656138707566 deg/30 m
Point→well    36.07373978320975 m
Well↔well     10.158905133826751 m
2D same-Z     20.303884894460907 m
UTM Easting   699163.3905617252 m
UTM Northing  9314348.961580029 m
```

The local TypeScript validation run passed all 9 benchmark groups within the specified floating-point tolerances.

## Phase 2 database/import benchmark

A second fictional benchmark was added during Phase 2 to compare the original WTM 4.3 database engine with the typed WTM 1.0 database layer. It exercises:

- CSV/TSV parsing
- incomplete-row rejection
- duplicate-MD removal
- conflicting duplicate-MD first-row precedence
- angle derivation
- geometry-closure QC
- exported station values

The serialized WTM 4.3 and WTM 1.0 benchmark JSON outputs produced no diff.

No production company data is used in this benchmark.
